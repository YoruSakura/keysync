## 设备与实体输入

Android 16 小米平板 25053RP5CC，游戏横屏 3200×2136；Xiaomi Keyboard 与 2.4G Xiaomi Mi USB Receiver Mouse。设备操作使用普通无线 ADB；应用沿用已授权的 Root 输入模式。

1.61 实测使用 Debug / code28；正式包为相同功能代码的 Release/R8 / code29，本次发布未替换平板上的测试包。下表保留 1.60 的基础操作结果，新增两项 1.61 的实际反馈。

| 范围 | 已验证行为 |
| --- | --- |
| 终末地移动 | 实体 W/A/S/D 前左后右正常，松键即停 |
| 终末地操作 | Alt 切换瞄准并转视角，F1–F4 切人，Space 跳跃，瞄准后的左键攻击 |
| 滚轮 | 鼠标模式列表滑动，瞄准模式镜头拉近／拉远；后续方向按用户要求调整为普通 PC 方向 |

1.61 实际保存视角设置后只新增 `aim_sensitivity=0.5`，其他所有既有键值不变。备份统一输出 schema v4，保留独立视角与光标设置，兼容读取 v1/v2/v3。

## 尚未确认或保留事项

- 明日方舟 E 对轴、生息演算 Alt 的实际视角拖动、肉鸽 W／1 的实际技能落点，尚未进入对应场景验证。
- 原方案推荐 1600×900、144+ 帧。宏时序、灵敏度与超屏曲线等实现有 KeySync 自身约定，未声称与 MuMu 内部单位完全一致。
- 用户说明新版明日方舟已支持暂停部署；普通拖放已在暂停中完成部署，旧右键“划火柴”不再作为本次必测项。原宏保留，未宣称零帧效果通过实测。
- 终末地曾出现一次 InputManager 拒绝／超时，映射停止并清理后重新启动恢复；具体原因未定位。技能／连携等隐藏按钮尚未全部实测。
